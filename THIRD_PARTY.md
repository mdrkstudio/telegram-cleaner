# Зависимости

Зависимости устанавливаются через pip и сохраняют собственные лицензии:

| Компонент | Назначение | Лицензия |
| --- | --- | --- |
| [Telethon](https://github.com/LonamiWebs/Telethon) | Telegram API | MIT |
| [PySide6 / Qt Essentials](https://doc.qt.io/qtforpython-6/licenses.html) | Интерфейс | LGPL v3 / GPL v3 / коммерческая |
| [qrcode](https://github.com/lincolnloop/python-qrcode) | QR-код входа | BSD |
| [Pillow](https://github.com/python-pillow/Pillow) | Создание PNG | HPND |

PolyForm Noncommercial из LICENSE применяется к авторскому коду MDRK Studio. При распространении сборки с библиотеками Qt необходимо соблюдать условия выбранной лицензии Qt, включая уведомления и возможность замены библиотек при использовании LGPL.
